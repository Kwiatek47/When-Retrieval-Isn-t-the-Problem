## Findings

The current app is not passing the eval gates.

The main clinical failure pattern is emergency triage: the chatbot often produces a generic "consult a clinician" style refusal instead of a clear urgent referral for red-flag symptoms.

The PQA-L result is also weak, especially for `yes` labels. Retrieval hit rate is high, so the main regression is likely answer-label extraction, evidence interpretation, or answer policy rather than pure source retrieval.
